1.  SYSTEM REQUIREMENTS
================================================================================

To build from source:
  - Rust 1.70+ (install via https://rustup.rs/)
  - A C compiler (gcc, clang, or MSVC) for linking
  - git (to clone the repository)

Supported platforms:
  - Linux (primary target, fully tested)
  - macOS (secondary, most features work)
  - Windows (tertiary, limited support via cmd.exe)

Disk space:
  - ~500 MB for Rust toolchain + dependencies
  - ~10 MB for the compiled release binary


================================================================================
2.  OPTION 1: INSTALL FROM SOURCE (RECOMMENDED)
================================================================================

Step 1: Clone the repository:
  git clone https://github.com/Blaze12345-deluxe/BuffyCLI.git
  cd BuffyCLI

Step 2: Build the release binary:
  cargo build --release

Step 3: Install globally:
  sudo cp target/release/buffy /usr/local/bin/

Step 4: Verify the installation:
  buffy --version

Expected output:
  buffy v0.1.0

Step 5 (optional): Keep up to date:
  cd BuffyCLI && git pull origin master && cargo build --release && sudo cp target/release/buffy /usr/local/bin/buffy


================================================================================
3.  OPTION 2: INSTALL VIA CARGO
================================================================================

If you have Rust installed, you can install Buffy directly from the
repository:

  cargo install --git https://github.com/Blaze12345-deluxe/BuffyCLI.git

This downloads the source, compiles it, and places the binary in
~/.cargo/bin/buffy. Make sure ~/.cargo/bin is in your PATH.


================================================================================
4.  OPTION 3: PRE-BUILT BINARY
================================================================================

Download a pre-built binary from the releases page:
  https://github.com/Blaze12345-deluxe/BuffyCLI/releases

Example for Linux AMD64:
  wget https://github.com/Blaze12345-deluxe/BuffyCLI/releases/download/v0.1.0/buffy-v0.1.0-linux-amd64.gz
  gunzip buffy-v0.1.0-linux-amd64.gz
  chmod +x buffy-v0.1.0-linux-amd64
  sudo mv buffy-v0.1.0-linux-amd64 /usr/local/bin/buffy

Verify the SHA-256 checksum (displayed on the GitHub release page) before running the binary.


================================================================================
5.  POST-INSTALLATION SETUP
================================================================================

Shell Completion (recommended):
  eval "$(buffy --completion bash)"     # Bash
  eval "$(buffy --completion zsh)"      # Zsh
  buffy --completion fish | source      # Fish

To make completion permanent, add the eval line to your shell's rc file:
  echo 'eval "$(buffy --completion bash)"' >> ~/.bashrc

Add the official plugin repository:
  buffy --repo https://github.com/Blaze12345-deluxe/Buffy-Plugins
  (or: buffy --repo add https://github.com/Blaze12345-deluxe/Buffy-Plugins)

List configured repositories to confirm:
  buffy --repo list

Search for available packages:
  buffy --repo search

Buffy v0.1.2+ ships with pip-env pre-installed. Try it immediately:
  buffy pip-env
  (Creates a Python virtual environment in the current directory.)

Install additional packages:
  buffy --install docker-tools

Run a system check:
  buffy --doctor


================================================================================
6.  FIRST RUN
================================================================================

When you run "buffy" for the first time, it automatically:

1. Creates the ~/.buffy/ directory structure:
     ~/.buffy/commands/    - Installed .bsl files
     ~/.buffy/packages/    - Cached package metadata
     ~/.buffy/cache/       - Temporary downloads and cached indexes
     ~/.buffy/logs/        - Daily execution logs

2. Creates ~/.buffy/logs/<date>.log for daily logging.

3. Shows the welcome screen with usage hints:
     Buffy CLI Automation Framework
     A lightweight framework for creating and sharing terminal commands.
     ...
     Example: buffy pip-env


================================================================================
7.  ENVIRONMENT VARIABLES
================================================================================

SHELL:
  The shell used for executing RUN commands in BSL scripts.
  Default: /bin/sh (if not set).
  Buffy detects the user's preferred shell and uses it with the -c flag.

HOME:
  The user's home directory. Used to locate ~/.buffy/.
  Default: System home directory.
  The Buffy home path is: $HOME/.buffy/

GITHUB_TOKEN:
  GitHub API token for accessing private repositories.
  Optional. Only needed for private GitHub repos.
  The token must have "contents: read" permission.

PATH:
  Used by the system dependency checker and the discover feature.
  Buffy scans PATH for executables to verify system dependencies
  and detect installed development tools.
