>> Quick Start

Get Buffy installed and running your first command in under 2 minutes.

# 1. Install Buffy from source $ git clone https://github.com/Blaze12345-deluxe/BuffyCLI.git $ cd BuffyCLI && cargo build --release $ sudo cp target/release/buffy /usr/local/bin/
# 2. Add the plugin repository $ buffy --repo https://github.com/Blaze12345-deluxe/Buffy-Plugins
# 3. Try a bundled command (pre-installed in v0.1.2+) $ buffy pip-env Creating Python virtual environment... Virtual environment '.venv' created.
# 4. Search for and install plugins $ buffy --repo search docker $ buffy --install docker-tools
# 5. See all available commands $ buffy --help
