v0.1.2 -- 2026-07-28
================================================================================

Feature release adding bundled packages and command ambiguity resolution.

Release: https://github.com/Blaze12345-deluxe/BuffyCLI/releases/tag/v0.1.2

Added:
  - pip-env now ships pre-installed with Buffy. On first run, the script is
    automatically installed from an embedded resource (include_str!). No need
    to run "buffy --install pip-env" — it's available immediately. Idempotent
    and non-destructive (skips if already installed from another source).
  - Flat-lookup ambiguity resolution: when "buffy <command>" matches a .bsl
    file in multiple packages, the user is shown a numbered selection prompt
    instead of silently picking the first result alphabetically.

Changed:
  - AI/ module removed from this repo and moved to its own repository:
    https://github.com/Blaze12345-deluxe/Buffy-AI-Script-Maker

================================================================================
v0.1.1 -- 2026-07-28
================================================================================

Bug fix release addressing CLI parsing, URL resolution, and repo management.

Release: https://github.com/Blaze12345-deluxe/BuffyCLI/releases/tag/v0.1.1

Fixed:
  - --repo add <url> now properly captures both subcommand and URL.
    Root cause: Option<Vec<String>> in clap defaults to 1 value without
    num_args(1..). Now --repo, --install, and --alias all use num_args(1..)
    to accept multiple arguments correctly.
  - --repo <url> shorthand works without needing the 'add' subcommand.
    URLs starting with https://, http://, or github.com/ are auto-detected
    and added as repositories.
  - raw.githubusercontent.com URLs now use 'master' branch instead of 'main'
    to match the Buffy-Plugins repository's default branch.
  - --repair detects and replaces stale 'BuffyCLI/packages' repository URLs
    with the current default 'Blaze12345-deluxe/Buffy-Plugins'.
  - All hardcoded 'BuffyCLI' organization URLs updated to
    'Blaze12345-deluxe'.
  - trailing_var_arg removed from command field to fix --repo parsing.
  - Fixed stray 'e' typo in self_update error path.
  - Fixed broken doc comment in args.rs (concatenated lines).

v0.1.0 -- 2026-07-28
================================================================================

First official GitHub release with pre-built binary asset.
Release: https://github.com/Blaze12345-deluxe/BuffyCLI/releases/tag/v0.1.0

Initial release. Complete implementation of all core features.

Added:
  Phase 0 -- Project initialization
    - Rust project scaffolding with cargo init.
    - Module directory structure for all subsystems.
    - All crate dependencies (clap, serde, ureq, sha2, etc.).
    - Release profile with LTO and strip optimization.
    - Test fixture directories.

  Phase 1 -- Configuration manager
    - Unified BuffyError enum with thiserror derives and user-facing tips.
    - Platform path resolution via dirs crate.
    - ~/.buffy/ home directory layout with ensure_directories().
    - JSON config file management: read/write config.json, installed.json,
      repositories.json.

  Phase 2 -- Logger
    - Colored terminal output with write(), success(), error(), warning(),
      info() functions.
    - tracing subscriber initialization for structured logging.

  Phase 3 -- BSL interpreter core
    - AST types: BslScript, Metadata (Version, Author, Description, Output),
      Statement (Write, Run, Wait, Clear, Exit, SetOutput), Token.
    - Line-based lexer with comment stripping and line numbers.
    - Parser with metadata validation, instruction parsing, and
      UnknownInstruction rejection.
    - Variable resolver for ${HOME}, ${USER}, ${PWD}, ${TEMP}, ${DATE},
      ${TIME}, ${1} through ${N}.
    - Shell executor using detected user shell ($SHELL or /bin/sh).
    - Interpreter with sequential execution and stop-on-error behavior.

  Phase 4 -- CLI and resolver
    - Clap-based CLI with 25 flags covering all operations.
    - Directory-walking command resolver with 5 resolution priorities.
    - Alias resolution before directory walking.
    - Flat lookup fallback for single-argument commands.

  Phase 5 -- Repository manager
    - Install source type parsing (local, GitHub, configured).
    - Repository index data structures with version comparison.
    - GitHub HTTP integration with local caching of indexes.
    - Cross-repository package search and discovery.

  Phase 6 -- Package manager
    - Install from 4 sources: local file, GitHub URL, configured repos,
      bulk @ wildcard.
    - Per-file SHA-256 verification with backward-compatible legacy support.
    - Name conflict detection and resolution with user-prompt caching.
    - System and BSL dependency resolution with circular dependency
      detection.
    - Package update mechanism with version checking.
    - Package uninstall with dependent-package warnings.
    - System tool discovery (scans 46 tools on $PATH).

  Phase 7 -- Diagnostics
    - System doctor with 11 checks (directories, config, SHA, connectivity,
      dependencies).
    - BSL linter with 9 check types (metadata, empty instructions,
      destructive commands, maintainability).
    - Metadata validator.
    - Benchmark runner (3 timed runs with warm-up).
    - Self-update checker via GitHub API.
    - Configuration repair and reset utilities.

  Phase 8 -- Name conflicts and aliases
    - Conflict detection by SHA comparison.
    - User-prompt resolution with persisted caching.
    - Alias management (create, list, resolve, remove).
    - Conflict preference storage in aliases.json.

  Phase 9 -- Polish and documentation
    - Shell completion generation (bash, zsh, fish, elvish, powershell).
    - Welcome screen with usage hints.
    - Error messages with helpful suggestions in every variant.
    - CI pipeline (GitHub Actions: build, test, clippy, fmt-check).
    - 9 real-world BSL example scripts.
    - 77+ unit and integration tests.
    - Test fixtures (8 scripts, 2 mock packages, mock buffy home).
    - README, CONTRIBUTING, SECURITY, CHANGELOG documentation.

Fixed:
  - Lexer no longer incorrectly parses "=" inside string arguments.
  - Interpreter correctly handles runtime OUTPUT toggle mid-script.
  - Linter handles all Statement variants exhaustively.
  - Uninstall removes unused variable causing compiler warning.
  - Test stability via shared TEST_HOME_LOCK mutex for HOME-dependent tests.
  - SHA verification changed from combined to per-file hashes for
    maintainability.
