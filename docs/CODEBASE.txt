1.  src/main.rs
================================================================================

Purpose: Binary entry point.

Contents:
  fn main() -> anyhow::Result<()>
    Calls buffy::run(). The entire application is in lib.rs.
    This file is the thinnest possible wrapper.

2.  src/lib.rs
================================================================================

Purpose: Library root. Declares all modules and provides the run() function.

Public:
  fn run() -> anyhow::Result<()>
    Entry point called from main(). Initializes directories, logging, and
    dispatches to cli::dispatch::execute().

Private:
  fn init_logging() -> std::io::Result<()>
    Creates ~/.buffy/logs/<date>.log and sets up tracing subscriber.

Modules exported:
  cli, config, diagnostic, logger, bsl, package, repository, resolver, error

3.  src/error.rs
================================================================================

Purpose: Unified error types for the entire project.

Key types:
  enum BuffyError
    BslSyntax            - BSL parse error with path, line, message.
    BslRuntime           - Runtime execution error with command, exit code, stderr.
    UnknownInstruction   - Invalid BSL instruction with line number.
    CommandNotFound      - Unresolvable BSL command.
    PackageNotFound      - Package not in any repository.
    PackageVerificationFailed - SHA-256 mismatch.
    InvalidManifest      - Corrupt or missing package.json.
    RepositoryConnection - Network failure contacting GitHub.
    ConfigError          - Invalid configuration file.
    Io                   - IO error wrapper (from std::io).
    Json                 - JSON parse error (from serde_json).
    Http                 - HTTP error (from ureq).
    DependencyError      - Dependency resolution failure.
    CircularDependency   - Circular dependency detected.
    MissingSystemDependency - Required tool not on $PATH.

  type Result<T> = std::result::Result<T, BuffyError>

Each error variant includes a #[error] display message with user-facing tips.

5.  src/cli/dispatch.rs
================================================================================

Purpose: Routes CLI flags to appropriate subsystem handlers.

Key function:
  fn execute(args: CliArgs) -> Result<()>
    This is the main dispatcher. It checks flags in priority order and calls:
      print_version()        - Print version string.
      print_about()          - Display project info.
      show_welcome()         - Welcome screen with usage.
      list_commands()        - Scan ~/.buffy/commands/.
      run_doctor()           - Full system diagnostics.
      self_update/check_update - Check GitHub for new releases.
      clean_cache()          - Remove cached files.
      repair()               - Fix configuration issues.
      reset()                - Reset to defaults.
      discover()             - System tool discovery.
      install_packages()     - Package installation.
      uninstall_package()    - Package removal.
      update_all/one_package - Package updates.
      show_info()            - Package metadata display.
      show_outdated()        - List packages with updates.
      verify_package()       - SHA-256 integrity check.
      manage_repositories()  - Repo CRUD operations.
      manage_aliases()       - Alias CRUD operations.
      manage_logs()          - View/clear log files.
      check_syntax()         - BSL syntax validation.
      validate_metadata()    - Metadata check.
      run_script()           - Execute .bsl directly.
      benchmark_script()     - Timing measurement.
      generate_completion()  - Shell completion output.
      execute_bsl_command()  - Resolve + run BSL command.

  fn check_for_update() -> Result<Option<(String, String)>>
    Fetches GitHub API for latest release tag and URL.

  fn repair() -> Result<()>
    Multi-step repair: ensure dirs, check/fix configs, remove orphans,
    verify SHA integrity.

  fn manage_repositories(args: Vec<String>) -> Result<()>
    Handles subcommands: list, add, remove, refresh, search.

  fn manage_aliases(args: Vec<String>) -> Result<()>
    Handles subcommands: list, set, remove, resolve.

  fn benchmark_script(path: String) -> Result<()>
    1 warm-up run + 3 timed runs with average reporting.

  fn generate_completion(shell: String) -> Result<()>
    Uses clap_complete to output shell completion script to stdout.

6.  src/resolver/tree.rs
================================================================================

Purpose: Resolves BSL commands by walking ~/.buffy/commands/.

Key function:
  fn resolve(args: &[String]) -> Result<PathBuf>
    Resolution algorithm:
      1. Resolve aliases for the first argument.
      2. For each argument:
           If last arg:
             Try exact file: <arg>.bsl
             Try index.bsl in <arg>/ directory
             Try <arg>/<arg>.bsl (directory name match)
             Try first .bsl alphabetically in <arg>/ directory
             Try flat lookup across all package directories
             Return CommandNotFound error
           Else:
             Walk into <arg> subdirectory

    Returns the OUTPUT setting from metadata. Defaults to true.

8.  src/bsl/lexer.rs
================================================================================

Purpose: Tokenizes raw BSL source text into a stream of tokens with line numbers.

Key function:
  fn tokenize(source: &str) -> Result<Vec<(usize, Token)>, BslError>
    Line-by-line processing:
      1. Strip BOM if present.
      2. For each line: trim, skip empties and comments.
      3. Strip inline comments (//).
      4. Tokenize: split metadata on =, split statements on whitespace.
      5. Append Newline and Eof tokens.

Private functions:
  tokenize_line(line, line_num) - Tokenizes a single non-empty line.
  tokenize_value(value, line_num) - Parses a quoted string, number, or bare value.


================================================================================
9.  src/bsl/parser.rs
================================================================================

Purpose: Parses a token stream into a BslScript AST.

Key function:
  fn parse(tokens: Vec<(usize, Token)>) -> Result<BslScript, BslError>
    Parsing phases:
      1. Filter out Newline tokens.
      2. Parse metadata section (VERSION, AUTHOR, DESCRIPTION, OUTPUT).
      3. Switch to statement mode on first non-metadata instruction.
      4. Parse WRITE, RUN, WAIT, CLEAR, EXIT, OUTPUT toggle.
      5. Return BslScript or error.

Private functions:
  is_metadata_keyword(ident) -> bool
  parse_metadata(tokens, pos, line) -> Result<Metadata, BslError>
  parse_statement(tokens, pos, line) -> Result<Statement, BslError>
  expect_string_arg(tokens, pos, line, instruction) -> Result<String, BslError>


================================================================================
10.  src/bsl/interpreter.rs
================================================================================

Purpose: Executes a parsed BSL script by walking the AST.

Key function:
  fn interpret(script: &BslScript, args: &[String]) -> Result<(), BslError>
    Execution loop:
      1. Read OUTPUT mode from metadata.
      2. For each statement:
           Write:      resolve variables, println.
           Run:        resolve variables, execute shell command.
           Wait:       sleep duration or read stdin prompt.
           Clear:      ANSI escape sequence.
           Exit:       break loop.
           SetOutput:  toggle output_enabled flag.
      3. If any RUN fails (non-zero exit), return CommandFailed error.

Private function:
  handle_wait(target: &WaitTarget) - Sleep or prompt user.

11.  src/bsl/executor.rs
================================================================================

Purpose: Spawns a shell process and executes commands.

Key types:
  struct ExecResult
    stdout: String, stderr: String, exit_code: i32, success: bool

Key function:
  fn execute(command: &str, output_enabled: bool) -> Result<ExecResult, BslError>
    Detects user shell from $SHELL env var (fallback: /bin/sh).
    Spawns shell with -c flag.
    If output_enabled: inherit stdout, pipe stderr.
    If not output_enabled: null stdout, pipe stderr.
    Returns ExecResult with exit code and captured output.

  fn clear_screen()
    Prints ANSI escape code: \x1B[2J\x1B[1;1H.

12.  src/bsl/variable.rs
================================================================================

Purpose: Expands ${VAR} placeholders in strings.

Key types:
  struct ExecutionContext
    args: Vec<String>

Key function:
  fn resolve(text: &str, ctx: &ExecutionContext) -> String
    Uses regex \$\{(\w+)\} to find variable references.
    Looks up each match in: built-in vars -> numbered args.
    Leaves unknown variables as-is.
    Regex prevents false prefix matches (${HOME} won't match ${HOMEDIR}).

Private function:
  builtin_variables() -> HashMap<String, String>
    Returns HOME, USER, PWD, TEMP, DATE, TIME from environment.

  install_all_from_github(repo) - Installs all packages from a repo.
  install_from_repositories(packages) - Searches configured repos.
  parse_github_repo(repo) - Extracts owner/name from URL.
